# Linux File Management Lab

This project contains Linux file and directory management practice.

## Commands Practiced

- date
- mkdir
- ls
- ls -l
- pwd
- touch
- clear
- cd
- cd ..
- rm
- rm -r
- rmdir
- cat
- echo
- head
- tail
- less
- more
- cp
- cp -r
- mv
- wc

## Learning Outcome

- Create directories
- Create files
- Read file contents
- Copy files and folders
- Move and rename files
- Delete files and directories
- Count words and lines
