# Linux System Level Commands

## uname
Shows system/kernel information.

```bash
uname
uname -a
uptime

Shows how long system has been running.

uptime
date

Displays current date and time.

date
who

Shows logged-in users.

who
whoami

Shows current user.

whoami
which

Shows command location.

which python
which bash
id

Shows user ID and group information.

id
sudo

Runs command with administrator privileges.

sudo apt update
apt

Package manager for Ubuntu/Debian.

apt --version
sudo apt update
sudo apt upgrade
reboot

Restarts the system.

sudo reboot
shutdown

Shuts down the system.

sudo shutdown now
